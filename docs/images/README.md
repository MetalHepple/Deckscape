# Screenshot provenance

The Deckscape screenshots in this directory were captured from the version
1.3.0 debug APK in an isolated Android emulator configured to 1920×1080 at
240 dpi. They contain no vehicle, account, map, or location information.

The interface is Deckscape project material. Wallpaper previews visible inside
the interface came from the public `fr0st-xyz/wallz` catalog and remain subject
to their respective creator and source terms. They are shown only to document
the application's user interface and are not covered by the project's MIT
